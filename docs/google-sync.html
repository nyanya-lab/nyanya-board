구글 캘린더 연결

냐냐 구글 계정에서 딱 한 번만 하면 돼요. 붙여넣는 코드는 자동 업데이트 버전이라 나중에 기능이 바뀌어도 다시 붙여넣을 필요가 없어요. 그 뒤로는 5분마다 알아서 맞춰요. 사이트에서 구글 로그인은 필요 없어요. PC에서 하는 걸 추천해요 (10분 정도). 욱진 보드와 같은 방식이에요.

이렇게 맞춰져요:
  • 📌 할 일 / ✅ 끝낸 일 → 김윤아 캘린더 (보드에서 날짜 있는 할 일)
  • 📖 스페인어 12개 · 복습 끝 → 루틴관리 캘린더 (공부한 날, 최근 60일. 보드 ⚙️ 설정 → 연동에 스페인어 비밀번호가 있어야 해요)
  • 💰 돈은 안 보내요.
  • 구글 캘린더 일정 → 보드 달력 (보드 ⚙️ 설정 → 구글 캘린더에서 캘린더마다 켜고 끄기)
보드가 넣은 일정만 고치고 지워요. 냐냐가 구글에서 직접 넣은 일정은 건드리지 않아요.

  1. Apps Script 열기

    냐냐 구글 계정으로 로그인한 상태에서 script.google.com 새 프로젝트를 열어요.

    구글 계정이 여러 개면 오른쪽 위 동그라미 사진이 '김윤아'·'루틴관리' 캘린더가 있는 계정인지 꼭 확인해요.

  2. 프로젝트 이름 바꾸기

    왼쪽 위 제목 없는 프로젝트를 눌러 냐냐 보드 동기화로 바꿔요.

  3. 코드 붙여넣기

    가운데 편집기에 있는 function myFunction() { … }을 전부 지우고, 아래 코드를 코드 복사로 복사해서 붙여넣어요.

    불러오는 중…

  4. 보드 비밀번호 넣고 저장

    코드 위쪽 const BOARD_PASSWORD = "";의 따옴표 사이에 냐냐 보드 비밀번호를 넣어요. 예: const BOARD_PASSWORD = "비밀번호";

    그다음 저장(디스크 아이콘, 또는 Ctrl + S)을 눌러요.

    이 코드는 냐냐 구글 계정 안에만 있어서 다른 사람은 못 봐요.

  5. Google Calendar API 추가

    왼쪽 메뉴 서비스 옆 +를 누르고, 목록에서 Google Calendar API를 골라 추가를 눌러요.

  6. setup 실행하고 권한 허락

    • 편집기 위쪽 함수 고르는 칸에서 setup을 고르고 ▶ 실행을 눌러요.
    • 권한 검토 → 냐냐 계정 선택.
    • "Google에서 확인하지 않은 앱" 화면이 나오면 고급 → 냐냐 보드 동기화(으)로 이동(안전하지 않음)을 눌러요. 냐냐가 직접 만든 스크립트라서 나오는 화면이에요.
    • 허용을 눌러요.

  7. 끝! 확인하기

    아래 실행 로그에 설정 끝! 이제 5분마다 자동으로 맞춰요.가 나오면 성공이에요.

    냐냐 보드 ⚙️ 설정 → 📅 구글 캘린더에 "자동 동기화 중"과 캘린더 목록이 보여요. 보드 달력에 보일 캘린더를 거기서 골라요.

문제 해결

"BOARD_PASSWORD에 냐냐 보드 비밀번호를 넣고…"4번에서 비밀번호를 넣고 저장했는지 확인해요.
"이 비밀번호로 만든 냐냐 보드가 없어요"비밀번호에 오타가 있어요. 사이트에서 쓰는 비밀번호와 똑같이 넣어요.
"Calendar is not defined"5번(서비스에 Google Calendar API 추가)이 빠졌어요.
보드에 "'김윤아' 캘린더를 못 찾았어요"가 떠요구글 캘린더 왼쪽 목록의 이름과 똑같아야 해요. 이름을 바꿨으면 알려 주세요 (코드에서 맞춰 드릴게요). 그동안 할 일은 기본 캘린더로 들어가요.
보드에 "구글 동기화 멈춤"이 떠요Apps Script 왼쪽 트리거(시계 아이콘)에 sync가 있는지 봐요. 없으면 setup을 다시 실행해요. 실행 메뉴(목록 아이콘)에서 빨간 실패 기록을 누르면 이유가 보여요.
보드 비밀번호를 바꿨어요4번처럼 새 비밀번호로 고치고 저장하면 다음 5분부터 새 보드로 맞춰요.
바뀐 기능을 지금 바로 받고 싶어요함수 칸에서 refresh를 골라 실행해요. (그냥 두면 15분 안에 알아서 바뀌어요)
그만 쓰고 싶어요함수 칸에서 stop을 골라 실행하면 자동 동기화가 멈춰요.
