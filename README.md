# 냐냐 보드

냐냐의 달력·할 일 보드. 스페인어 공부방·Watch LOG를 한곳에서 보고, 가계부의 공통비용은 욱진이와 같이 써요.

사이트: https://nyanya-lab.github.io/nyanya-board/

| 메뉴 | 내용 |
|---|---|
| 달력 | 첫 화면. 위에 오늘 요약 4칸, 한 달 달력, 날짜를 누르면 그날 할 일 보기·추가·체크 |
| 스페인어 | 오늘 복습 상태 · 🔥 연속 공부일 · 최근 2주 (스페인어 공부방 기록 읽기) |
| 왓치로그 | 보는 중 · 이번 달/올해 다 본 작품 (Watch LOG 기록 읽기) |
| 가계부 | (준비 중) 욱진 보드 가계부 기반 |
| 우리 | 🤝 욱진이와 같이 쓰는 공통비용 (공통 비밀번호) |
| 설정 | 저장 상태 · 백업 · 연동 비밀번호 · 잠그기 |

처음 열 때 비밀번호를 정하면, 폰·PC 어디서든 같은 비밀번호로 같은 보드가 열려요 (Firebase, 욱진 보드와 같은 방식).

## 배포

GitHub Pages: 저장소 Settings → Pages → Source *Deploy from a branch* → `main` / `/docs`.
`main`에 올리면 1~2분 뒤 사이트에 반영돼요.

## 로컬에서 미리 보기

```bash
python -m http.server 8010 --directory docs
```
→ http://localhost:8010

## 폰 홈 화면에 앱처럼 두기

아이폰: 사파리로 사이트 열기 → 공유 → **홈 화면에 추가**
